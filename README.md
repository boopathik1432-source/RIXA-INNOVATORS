# RIXA-INNOVATORS

## RIXA Nexus — Web3 & Smart Education Blog

A modern, editorial blog website built with **Astro.js**, **Motion.dev**, and custom **CSS** following a refined light-theme Web3 design system combining the minimalism of Apple, usability of Google, modern polish of Meta, and subtle digital accents of Web3.

### Tech Stack
* **Framework:** [Astro.js](https://astro.build/)
* **Animation:** [Motion.dev](https://motion.dev/)
* **Styling:** Vanilla CSS with custom design tokens
* **Language:** TypeScript

### Getting Started

Install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```

Build static production bundle:
```bash
npm run build
```

Preview static build locally:
```bash
npm run preview
```
